# Support

This plugin has a solo maintainer, so support is best-effort with no SLA.

- **Questions and bugs:** open a [GitHub issue](https://github.com/zachshallbetter/claude-jev/issues/new/choose).
  `/jev:jev doctor` reports the configuration it found, which helps a bug report; remove any key or private text
  before pasting.
- **Security reports:** follow [SECURITY.md](SECURITY.md) and report privately.
- **Versions:** releases are tagged `vX.Y.Z` and listed in [CHANGELOG.md](CHANGELOG.md). Fixes go into the latest
  tagged release.
